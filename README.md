# Ressa Joki — Website Joki Explore Genshin Impact

## File
- `index.html` — struktur halaman
- `style.css` — desain/responsive
- `script.js` — data harga, accordion, pencarian, WhatsApp, animasi

## Sebelum upload ke GitHub
Nomor WhatsApp admin sudah disetel di `script.js` ke nomor Ressa Joki.

Format nomor: kode negara tanpa `+`, spasi, atau tanda baca.

Gunakan format nomor Indonesia tanpa `+`, spasi, atau tanda baca.

## GitHub Pages
1. Buat repository baru, misalnya `ressa-joki`.
2. Upload `index.html`, `style.css`, dan `script.js`.
3. Buka **Settings → Pages**.
4. Pada Source pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/root`.
6. Simpan. GitHub akan memberikan alamat GitHub Pages.

Website tidak membutuhkan database atau hosting backend.
